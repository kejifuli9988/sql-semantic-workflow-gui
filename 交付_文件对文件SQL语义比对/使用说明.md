# 文件对文件 SQL 语义比对小软件使用说明

这个文件夹里的小软件，负责两件事：

1. 生成 `prepare.json` 和 `prepare_part_x.json`
2. 合并 `review_results_part_x.json` 并输出最终 Excel

中间真正的 SQL 语义判断，仍然交给你的行内智能体处理。

## 文件说明

- `compare_sql_files.py`
  - 核心处理脚本
  - 负责读取 Excel、兼容 HTML `.xls`、生成 prepare、拆分批次、合并 review 结果、输出 Excel
- `sql_semantic_workflow_gui.py`
  - 图形界面
  - 适合日常点选文件使用
- `build_windows_exe.bat`
  - Windows 打包脚本
- `skill.md`
  - skill 说明
- `智能体角色定义.md`
  - 智能体角色定义

## 依赖安装

先安装依赖：

```bash
pip install pandas openpyxl xlrd lxml
```

如果你要打包成 exe，再额外安装：

```bash
pip install pyinstaller
```

## 启动方式

在这个文件夹下执行：

```bash
python sql_semantic_workflow_gui.py
```

会打开一个图形界面。

## 图形界面使用流程

### 第 1 步：选择输入文件

- 选择主文件
- 选择对比文件
- 如有需要，填写：
  - 主文件 SQL 列
  - 对比文件 SQL 列
  - 主文件主键列
- 默认：
  - `top_k = 3`
  - `batch_size = 20`

如果你不确定列名，可以先点：

- `查看主文件列名`
- `查看对比文件列名`

如果你想自己在终端执行，也可以直接点：

- `复制 Prepare 命令`
- `复制 Finalize 命令`

## 第 2 步：生成 Prepare 并拆分

点击：

```text
1. 生成 Prepare 并拆分
```

软件会在结果目录下生成：

- `prepare.json`
- `prepare_parts/prepare_part_1.json`
- `prepare_parts/prepare_part_2.json`
- ...

同时界面下方会自动生成一段“给智能体的提示词”。

这段提示词是“一次性处理所有批次”的总提示词。

如果你想直接查看输出位置，也可以点：

- `打开结果目录`

## 第 3 步：把提示词给智能体

点击：

```text
复制提示词
```

然后把提示词粘贴到你的行内智能体窗口。

智能体需要根据这些 `prepare_part_x.json`，分别生成：

- `review_results_part_1.json`
- `review_results_part_2.json`
- ...

注意：

- 每个 part 单独一个 JSON
- 不要把多个批次混在一个文件里
- 不要漏 `pair_id`
- 不要重复 `pair_id`

## 第 4 步：合并并生成 Excel

当所有 `review_results_part_x.json` 都准备好后：

方式一：
- 点击 `自动发现 review_results_part 文件`

方式二：
- 点击 `选择 review_results_part 文件`

然后点击：

```text
4. 合并并生成 Excel
```

软件会自动生成：

- 最终 Excel
- 同名 JSON 底稿
- 合并后的 `review_results.json`

生成完成后，也可以直接点：

- `打开最终 Excel`

## 最终输出

最终 Excel 默认包含三个工作表：

- `汇总`
- `逐条语义比对`
- `候选明细`

其中：

- `汇总`
  - 统计总条数、同一业务 SQL 数量等
- `逐条语义比对`
  - 每条主 SQL 的最终匹配结果
- `候选明细`
  - 每个候选的粗召回和模型判断结果

## 命令行模式

如果你不想用 GUI，也可以直接用命令行。

### 1. 生成 prepare

```bash
python compare_sql_files.py \
  --mode prepare \
  --base 主文件.xlsx \
  --target 对比文件.xls \
  --base-sql-column "SQL语句" \
  --target-sql-column "SQL语句" \
  --base-id-column "任务编号" \
  --top-k 3 \
  --output result/prepare.json
```

### 2. 拆分 prepare

```bash
python compare_sql_files.py \
  --mode split-prepare \
  --prepared result/prepare.json \
  --batch-size 20 \
  --output-dir result/prepare_parts
```

### 3. 合并 review 结果

```bash
python compare_sql_files.py \
  --mode merge-review-results \
  --review-results-files result/review_results_part_1.json result/review_results_part_2.json \
  --output result/review_results.json
```

### 4. 生成最终 Excel

```bash
python compare_sql_files.py \
  --mode finalize \
  --prepared result/prepare.json \
  --review-results result/review_results.json \
  --output result/final_result.xlsx
```

## 打包成 Windows EXE

在 Windows 电脑里进入这个交付目录后执行：

```bat
build_windows_exe.bat
```

打包完成后会生成：

```text
dist\SQL语义比对工作流.exe
```

这样没有 Python 的 Windows 电脑也可以直接运行。

## 常见问题

### 1. `.xls` 打不开

有些 `.xls` 实际上是 HTML 导出的表格，不是真正的二进制 Excel。

这个工具已经兼容这种情况，会自动按 HTML 表格读取。

### 2. 智能体输出被截断

如果你的智能体经常把大 JSON 写断，建议：

- 保持 `batch_size = 20`
- 一次处理一个 `prepare_part`
- 或者用界面自动生成的总提示词，让它按 part 顺序逐个输出

### 3. 合并时报重复 `pair_id`

说明不同 `review_results_part_x.json` 里写进了重复结果。

这时需要检查：

- 是否把同一个 part 跑了两遍
- 是否把别的 part 的 `pair_id` 混进来了
- 是否复制结果时重复了
