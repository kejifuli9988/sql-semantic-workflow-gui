# EXE 版使用说明

这个文件夹是 `exe版`，适合给最终用户直接使用。

## 文件

- `compare_sql_files.py`
- `sql_semantic_workflow_gui.py`
- `build_windows_exe.bat`
- `skill.md`
- `智能体角色定义.md`

## 分工

- exe / GUI 负责：
  - 生成 `prepare.json`
  - 拆分 `prepare_part_x.json`
  - 合并 `review_results_part_x.json`
  - 生成最终 Excel
- 智能体负责：
  - 只处理 `prepare_part_x.json`
  - 生成对应 `review_results_part_x.json`

## 使用流程

1. 运行 `sql_semantic_workflow_gui.py` 或打包后的 exe
2. 选择主文件、对比文件、列名
3. 点击 `1. 生成 Prepare 并拆分`
4. 点击 `2. 刷新并复制提示词`
5. 把提示词给智能体，让它生成全部 `review_results_part`
6. 点击 `3. 合并 review_results_part 生成 Excel`

## 说明

- 这一版偏“桌面小软件”
- 智能体只负责 review，不负责 Excel 输入输出
- 最终结果统一由本地工具生成
